tldr: A framework for feature generation from heterogeneous behavioral and transactional data that significantly improves classification accuracy in business and financial applications.
problem_and_motivation: Automated feature generation often underperforms because it fails to incorporate domain expertise or adapt to data structure. A systematic approach is needed to generate expert-informed features for classification on behavioral data.
approach:
  - Data sources include events tables per channel, customer segmentation, and outcome tables with binary labels.
  - Features are generated by selecting configuration parameters such as channel, response, customer segment, trigger segment, time interval, and statistics.
  - Feature validation uses Monte Carlo simulation with random forest on small feature batches.
  - Feature selection ranks features by a composite score of importance, AUC, and AUC-PR.
  - Model training and selection compare logistic regression, GAMs, random forest, gradient boosting, and neural networks.
findings:

  - num: The credit scoring model achieved an average Gini of 62%, significantly outperforming legacy models.
  - The feature generation approach improved model accuracy up to threefold compared to off-the-shelf feature engineering.
