# Specifications

## System Specification

`system-spec.md` — the system specification (v0.1.0, 2026.08.05). This is the **main design contract** for Odin: system overview, glossary, architecture, user roles and personas, Personal Financial Profile (PFP) specification, functional requirements, ML model specifications, data specification, non-functional requirements, external interfaces, constraints and assumptions, and dependencies.

> The document is a working draft — most sections are still `TODO:` outlines with guidance comments. The historical v4.0 spec is preserved at `../system/specification (OLD).md`.

## Rules

- This directory is the **canonical location** for the current system specification. Do not create competing spec copies elsewhere.
- When the specification changes, update the Metadata block (version, date).
- Superseded specifications are preserved with an `(OLD)` marker under `../system/`.
