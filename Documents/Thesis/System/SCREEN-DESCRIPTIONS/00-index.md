## Notes

- Mobile-first behavior applies to all core workflows.
- Desktop web screens support the same core workflows with more room for analysis and reporting.
- Forecasting requires a server connection; other core processes should be offline-capable.
- Recommendations, forecasts, profile classifications, and alerts must be explained as decision support, not licensed financial advice.
